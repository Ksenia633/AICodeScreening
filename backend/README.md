# AI Code Screening — Backend

FastAPI-сервис для курсовой работы. Он получает ссылку на публичный GitHub-репозиторий, загружает дерево исходников через GitHub REST API, рассчитывает эвристические признаки подозрительных участков и формирует вопросы для технического интервью.

## Запуск

```bash
cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Проверка: `GET http://localhost:8000/health`.

Для Android Emulator backend на компьютере доступен по `http://10.0.2.2:8000`.

## Ограничение анализа

Проект не заявляет, что по одному коду можно достоверно доказать авторство нейросети. Результат — screening-сигнал для HR, который должен использоваться вместе с вопросами на собеседовании.

GitHub REST API позволяет получать содержимое файлов репозитория и дерево Git-объектов; для публичных ресурсов запросы могут выполняться без аутентификации, хотя токен повышает лимит запросов.
