# AI Code Screening

Мобильное Android-приложение для HR и IT-рекрутеров, которое помогает проводить первичный screening разработчиков.

## Текущий режим MVP

Приложение работает **автономно**: после установки не требуется запускать Python/FastAPI, вводить GitHub URL или подключать `localhost:8000`.

Внутри APK используется локальная SQLite-база с демонстрационными кандидатами, результатами анализа, подозрительными участками и вопросами для технического интервью.

### Возможности

- список кандидатов из локальной базы;
- карточка кандидата;
- screening-score;
- найденные участки кода и причины для дополнительной проверки;
- автоматически подготовленные вопросы для интервью;
- работа без backend на компьютере и без сети для демонстрационного сценария.

## Архитектура автономного MVP

```text
Android / Kotlin / Jetpack Compose
            |
            v
     MainActivity.kt
            |
            v
   ScreeningDatabase.kt
            |
            v
       SQLite DB
            |
            +---- candidates
            +---- findings
            +---- questions
```

## Онлайн-анализ

В репозитории также сохранён `backend/` на FastAPI как следующий этап проекта. Он может использоваться позже для анализа новых публичных GitHub-репозиториев через GitHub REST API. Основной демонстрационный Android-сценарий от него не зависит.

## Запуск Android

Открой корень проекта в Android Studio, дождись Gradle Sync и запусти `app` на Android Emulator. Для демонстрационного режима Python и uvicorn запускать не нужно.

Проект настроен на Android Gradle Plugin 8.13.2, Gradle 8.13, Kotlin 2.3.21 и Java 17.

### Если Android Studio показывает ошибку Gradle

1. Закрой Android Studio.
2. Удали локальную папку `.gradle` внутри проекта, если она есть.
3. Запусти Android Studio снова.
4. Выполни `File → Sync Project with Gradle Files`.
5. Если Android Studio предлагает выбрать Gradle JDK, выбери JDK 17.

## Важное ограничение

Приложение не утверждает, что способно со 100% точностью установить, был ли код создан нейросетью. Score — это вспомогательный сигнал для дополнительной проверки. Финальная оценка кандидата должна основываться на совокупности данных и техническом интервью.

## Идея курсовой

Проблема: HR сложно самостоятельно проверить реальный опыт разработчика по GitHub.

Решение: автоматизировать первичный анализ проектов и подготовку вопросов, позволяющих проверить понимание кандидатом собственного кода.
